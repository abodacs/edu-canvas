# Agent instructions

Before changing or reviewing code, read [code standards](docs/engineering/code-standards.md). Follow its linked [coding patterns](docs/engineering/coding-patterns.md) when working on domain rules, integrations, state transitions, errors, or PR scope.

When changing imports, shared contracts, or server delivery seams, read the [architecture harness](docs/architecture-harness.md) and preserve its boundaries.

Use the commands in [package.json](package.json). Run checks relevant to the changed files before handing off work.
