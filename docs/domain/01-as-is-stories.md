# As-is stories

**Status: reconstructed, not observed.** No teacher interview, lesson recording, or classroom observation exists in this repository. See [observed behaviour](../observed-behaviour.md). These stories were rebuilt from the desk study in [#94](https://github.com/abodacs/edu-canvas/issues/94) and from the seed lesson's own sequence. They are a hypothesis about the work, not a record of it. A teacher reads them aloud and corrects them before any of them counts as evidence.

## Rules these stories follow

- No software actor. No product, model, screen, or notification. A pen and a photocopier are allowed; an app is not.
- One story, one case. The 80% case only. Alternatives become their own story.
- Numbered sentences with the grammar actor → activity → work object. Every sentence reads aloud.
- No conditionals. "If the student is wrong" becomes its own story.

## Story 1 — Prepare and approve one lesson

**Actors:** Teacher, Colleague. **Work objects:** curriculum standard, learning objective, source material, draft lesson, answer key, feedback text, class list.

1. Teacher selects a curriculum standard.
2. Teacher writes a learning objective from the standard.
3. Teacher gathers source material: a textbook page and a past worksheet.
4. Teacher drafts a lesson with a worked example, guided practice, and an independent check.
5. Teacher writes the answer key for the independent check.
6. Teacher writes feedback for a wrong answer.
7. Teacher sets the lesson beside the class period and cuts one activity.
8. Teacher notes the prerequisite knowledge the lesson assumes.
9. Teacher reviews the draft the next morning.
10. Teacher corrects an example that had two possible answers.
11. Teacher gives the draft to a colleague.
12. Colleague marks two instructions as unclear.
13. Teacher approves the lesson.
14. Teacher files the approved lesson with the class materials.

## Story 2 — Teach and read the responses

**Actors:** Teacher, Student, Class. **Work objects:** worked example, guided step, student answer, feedback, independent work, class list, misconception note, next activity.

1. Teacher presents the worked example on the board.
2. Teacher asks a student to complete a guided step.
3. Student writes an answer.
4. Teacher reads the answer and marks it.
5. Teacher gives feedback to the student.
6. Student starts the independent check.
7. Teacher collects the independent work.
8. Teacher sorts the work into correct, partial, and wrong piles.
9. Teacher reads two wrong answers and names one misconception.
10. Teacher writes the misconception on the class list.
11. Teacher chooses the next activity for the class.

## Story 3 — Choose the next activity for one student

**Actors:** Teacher, Student. **Work objects:** student independent work, earlier student work, prerequisite activity, activity sheet.

1. Teacher reads the student's independent work.
2. Teacher compares it with the student's earlier work.
3. Teacher selects a prerequisite activity.
4. Teacher writes the student's name on the activity sheet.
5. Student completes the prerequisite activity.
6. Teacher files the sheet with the student's work.

## What the stories show

- The teacher's week has three hand-overs: draft → approved lesson, approved lesson → taught lesson, taught lesson → next activity.
- Two work products move between people: **student work** and **the approved lesson**. Nothing else does.
- The words the teacher uses are _standard, objective, example, answer key, feedback, independent work, misconception, next activity_. The code uses none of them in that sense. See [the homonym register](03-homonyms.md).
- Review, not drafting, is where the teacher's judgement sits. Drafting moves work; review decides.
