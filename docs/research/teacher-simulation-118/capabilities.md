The broader matching design uses **native confidence > 0.90** to skip match confirmation for supported objectives; **0.90 or below requires confirmation**. Unsupported objectives remain unsupported at any confidence. An unavailable Jev service permits manual confirmation only with source grounding available. Missing standard or required skills follows the proposed grounding recovery route; missing prerequisites alone can proceed with a visible gap. These are proposed rules from the pinned teacher UI document, not provider accuracy or implemented behavior. Confidence never approves content, grades work or establishes maths correctness.
