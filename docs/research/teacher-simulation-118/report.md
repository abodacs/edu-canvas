## What this rehearsal can change

Use these cases to improve the study protocol. Ask about reusable materials before showing the product. Include review, correction, setup, sharing, and follow-up in every comparison. Record help and refusals. Ask about actual later use separately from stated preference. Keep inaccessible tools and unsupported tasks separate from product quality.

The selected scenarios do not establish how common any obstacle is. They do not justify a feature priority without real observation. Shared model behavior and authored probes can shape every result.
