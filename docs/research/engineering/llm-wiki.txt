uilding my LLM wiki, I introduced a simple rule:

A concept only gets its own page when it appears in at least 2 different sources.

Here's how ingestion works:

1. Copy the original document into raw/.
2. Create a source page with the key insights.
3. Use an LLM to extract entities and concepts.
4. Merge recurring concepts into dedicated Markdown pages.
5. Rebuild the indexes using a Python script.


------------
It's basically a lightweight version of GraphRAG built entirely with Markdown files.
