Here are **5 strong, high-potential winning ideas** tailored to the Meta Global AI Developer Hackathon:

### 1. Domain Expert Agent with Persistent Memory (Build for Your World – Indie or Startup)
Build a highly specialized personal AI agent for a real profession you know well (e.g., independent researcher, small-scale farmer, freelance designer, or local clinic doctor).  
Leverage **Muse Wonder / Muse Spark’s long context + Active Memory/Active Focus** so the agent remembers the user’s preferences, past decisions, documents, and tools across sessions. Add multimodal input (documents, images, voice) and the ability to take real actions (email, calendar, data analysis, simple tool use).  
**Why it can win**: Extremely clear fit for “Build for Your World,” high technical ambition with memory + agents, and very demoable in 10 days.

### 2. SAM 3.1 + Agent-Powered Visual Inspector (Push the Frontier)
Create a real-time visual inspection system for manufacturing, agriculture, or construction. Use **SAM 3.1** for precise segmentation and object understanding, then layer Muse models on top for reasoning, anomaly explanation, and automated reporting or robotic guidance.  
Example: Detect defects on a production line, identify crop disease from phone photos, or guide a drone/robot.  
**Why it can win**: Perfect “Push the Frontier” fit (physical world + new capability), heavy use of SAM 3.1 (a differentiator), and clear technical depth.

### 3. Full Product Builder Agent with Muse Code (Either Track)
An agentic system that takes a natural-language product idea and uses **Muse Code** (multi-agent orchestration) + Meta models to plan the architecture, write the full codebase, generate UI with Muse Image, set up deployment, write tests, and iterate based on feedback.  
Make it specialized (e.g., “build internal tools for small businesses” or “build research dashboards”).  
**Why it can win**: Directly showcases Meta’s newest agentic coding strengths. High technical ambition and very strong for the Startup track if you make it production-oriented.

### 4. Scientific Experiment Accelerator (Push the Frontier)
An AI co-scientist for materials science, energy, or biology that uses long-context multimodal models + tool calling to design experiments, analyze results (images/data via SAM + Muse), suggest next steps, and maintain a living experiment notebook with Active Memory.  
**Why it can win**: Excellent frontier theme match, shows the models meeting the real (scientific) world, and stands out from pure software demos.

### 5. Hyper-Personal Accessibility Companion (Build for Your World)
A multimodal agent that helps people with specific accessibility needs (visual, motor, cognitive, or language-related). Combine real-time vision (SAM 3.1 + camera), voice, long-term memory of the user’s environment and preferences, and proactive assistance.  
Example: Describes surroundings with high precision, remembers the user’s home layout, helps navigate new places, or assists with complex digital tasks.  
**Why it can win**: Deeply personal “Build for Your World” problem, strong technical ambition (multimodal + memory + real-time), and high emotional + practical impact that judges notice.

### Quick Tips for Winning
- Heavily feature **Meta’s unique tools** (Muse Code, SAM 3.1, Muse Image, long-context/memory features).
- Make the demo extremely clear and working — “whether it works” and technical execution matter a lot.
- Choose a problem you personally understand (stronger application + better final product).
- Scope tightly for 10 days: one core impressive capability + solid polish beats a half-finished ambitious system.

Here are **5 more high-potential winning ideas** for the Meta Global AI Developer Hackathon. These are distinct from the previous set and lean harder into Meta’s current strengths (Muse agents + memory, Muse Code, SAM 3.1 vision, long context, and multimodal capabilities).

### 6. Living Codebase Guardian (Push the Frontier / Startup track)
An always-on multi-agent system powered by **Muse Code + Muse Wonder** that continuously monitors a large existing codebase (or monorepo). It detects technical debt, security issues, performance regressions, and outdated patterns, then autonomously proposes, tests, and (with approval) applies improvements using long-horizon planning and parallel sub-agents.  
Include a clear dashboard of “what the guardian fixed this week” and a memory of past decisions.  
**Why it can win**: Extremely strong technical ambition + production relevance. Perfect for the Startup track and showcases Muse Code’s long-running agentic strengths.

### 7. Real-World Scene Understanding Agent (Push the Frontier)
A system that turns phone or webcam video into a structured, queryable “world model” using **SAM 3.1** for precise segmentation + Muse models for reasoning and memory. Users can ask natural language questions (“Where did I leave my keys?”, “Show me everything that changed in the kitchen since yesterday”, “Is this plant healthy?”) and get grounded answers with visual highlights.  
Add Active Memory so it builds a persistent understanding of the user’s spaces over days.  
**Why it can win**: Heavy, distinctive use of SAM 3.1 + long-context memory. Clear “give a machine a new capability” frontier feel and highly demoable.

### 8. Personalized Skill Coach with Embodied Practice (Build for Your World)
An agent that helps someone master a real-world skill they care about (public speaking, cooking a specific cuisine, woodworking, language conversation, music practice, etc.). It uses multimodal input (video of the user practicing, audio, photos of results), gives precise feedback with visual overlays via SAM/Muse Image, remembers progress and weak points across sessions, and adapts the next practice plan.  
**Why it can win**: Deeply personal “Build for Your World” problem, strong technical ambition with multimodal feedback loops, and high emotional resonance for judges.

### 9. Autonomous Research Literature & Experiment Companion (Push the Frontier)
A multi-agent system for scientists or technical founders that ingests papers, lab notes, and data. It maintains an Active Memory knowledge graph of the research area, suggests experiments or next papers, generates code for analysis or simulation, and can critique or improve experimental designs. Use Muse Code for any required tooling/scripts and long context for large literature sets.  
**Why it can win**: Excellent frontier theme match (accelerating scientific work), heavy agent + memory use, and clear path to production value for the Startup track.

### 10. Local-First Multi-Agent Workplace (Build for Your World or Startup)
A privacy-focused team of specialized agents (researcher, writer, analyst, coder, scheduler) that run primarily on Meta open-weights models + selective API calls. The system maintains shared and personal Active Memory, coordinates via Muse-style multi-agent orchestration, and works offline-first where possible. Target freelancers, small teams, or privacy-sensitive domains.  
**Why it can win**: Differentiated by privacy + multi-agent coordination, shows technical depth with open weights + Muse models, and has clear real-world product potential.

### Bonus guidance for any of these
- Make the core demo work reliably in under 2 minutes.
- Explicitly call out which Meta models/features you’re using (especially SAM 3.1, Muse Code, Active Memory/Focus, or long context).
- Scope for 10 days: one impressive core loop + polish > many half-finished features.
- For Indie track lean into creativity and ambition; for Startup track emphasize reliability and production readiness.

Here are **5 more fresh, high-potential winning ideas** for the Meta Global AI Developer Hackathon. These avoid repeating the previous suggestions and lean into the official themes (“Build for Your World” and “Push the Frontier”), heavy use of SAM 3.1 (especially video), Muse agents/memory, and Muse Code.

### 11. Personal Digital Twin of Your Home / Workspace (Build for Your World)
A persistent agent that builds and maintains a living visual model of the user’s home, desk, workshop, or small shop using phone video + **SAM 3.1** tracking. It remembers object locations, changes over time, and answers practical questions (“Where did I put the blue cable?”, “Has anything moved on the workbench?”, “What’s missing from the inventory shelf?”). Active Memory keeps long-term context; Muse models reason over the visual history.  
**Why it can win**: Extremely personal problem, distinctive SAM 3.1 video tracking use, and clear everyday utility that judges can instantly understand.

### 12. Autonomous Materials / Prototype Iteration Agent (Push the Frontier)
An agent system aimed at makers, small manufacturers, or materials researchers. Upload photos or video of a physical prototype or material sample → SAM 3.1 segments defects, features, or composition regions → Muse models suggest the next design change, generate code for simulation or 3D printing parameters (via Muse Code), and track the full iteration history with memory.  
**Why it can win**: Direct match for “materials and beyond” + “give a machine a new capability.” Strong technical ambition and physical-world relevance.

### 13. Multi-Object Video Intelligence Pipeline for Creators or Researchers (Indie or Startup)
A tool that takes raw video and uses **SAM 3.1** (open-vocabulary + multi-object tracking) to automatically segment, track, and label every instance of specified concepts (people, animals, products, tools, defects, etc.). Then a Muse agent reasons over the tracks to generate insights, timelines, summaries, or even new creative assets with Muse Image. Target wildlife monitoring, sports analysis, product testing, or content creation.  
**Why it can win**: Heavy, distinctive use of SAM 3.1’s video strengths (a clear differentiator vs. generic LLM projects). Highly demoable and scalable.

### 14. Long-Horizon DevOps / Infrastructure Agent (Startup track)
A specialized multi-agent system built around **Muse Code + Muse Wonder** that understands an entire infrastructure codebase (Terraform, Kubernetes manifests, CI/CD, monitoring configs). It can diagnose incidents from logs + code, propose and test fixes, generate rollback plans, and maintain memory of past outages and decisions. Focus on reliability and production readiness rather than pure code generation.  
**Why it can win**: Excellent technical execution story for the Startup track, showcases long-horizon agentic coding, and solves a painful real-world problem.

### 15. Adaptive Field Guide / Citizen Science Companion (Build for Your World)
A mobile-friendly agent for hikers, gardeners, birders, or local environmental monitors. Point the camera at a plant, insect, rock, or pollution sign → SAM 3.1 segments and tracks it → Muse models identify, explain, and remember previous sightings in the user’s area. Over time it builds a personal ecological memory and can suggest actions or contribute structured data.  
**Why it can win**: Clear “Build for Your World” domain, strong multimodal + memory combination, and positive real-world impact that stands out.

### Quick strategic notes
- Prioritize **SAM 3.1 video tracking** or **Muse Code long-horizon agents** — these are harder for competitors to fake and align with Meta’s newest releases.
- Keep the core demo tight: one impressive end-to-end loop that works reliably.
- For Indie track emphasize creativity and novelty; for Startup track emphasize reliability, edge cases, and production thinking.
- Explicitly name the Meta models/features in your application and demo.
