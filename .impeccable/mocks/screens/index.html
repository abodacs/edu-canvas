Flows, screen by screen

Flow Steps and where they live
Auth Sign up, sign in, membership pick (5), then workspace (1). Failures and expiry: 8.
Draft Prompt plus optional source, generate, four variants (1), then preview tabs and open review (2).
Review Edit one section as a new version, approve each variant and the learning path, acknowledge warnings (2), then publish and assign one learner (3).
Learner Link with assignment and variant, open the run, pair, Done, score (7). Loading, saving and error: 8.
Recovery Retry the same input and cancel generation (1), moderation block (6), review error dismiss (8).
Session Idle warning with continue or sign out (6), expired banner (8), signed-out banner (0).
