# Equivalent fractions — lesson source (Grade 4)

## Standard alignment

CCSS.MATH.CONTENT.4.NF.A.1 — Explain why a fraction a/b is equivalent to a
fraction (n × a)/(n × b) by using visual fraction models, with attention to
how the number and size of the parts differ even though the two fractions
themselves are the same size. Use this principle to recognize and generate
equivalent fractions.

## What students can already do

- Name fractions from area models with like denominators.
- Partition shapes into equal parts and count them.

## Core idea

Multiplying both the numerator and the denominator of a fraction by the same
nonzero whole number names the same amount on the same whole. The parts get
smaller and more numerous, but the covered area is unchanged.

## Worked example

A circle is shaded to show 1/2. Cut every part in two. The same shaded area
now shows 2/4. Record: 1/2 = 2/4. Repeat to reach 4/8.

## Guided practice ideas

- Paper-strip folding with paired recording.
- Fraction bars: match 1/3 with 2/6 and 3/9.
- Number line: mark 1/2 and 2/4 on the same line from 0 to 1.

## Independent check

Shade 2/3 of a rectangle, then shade 4/6 of a congruent rectangle. Explain to
a partner why the shaded areas are the same.

## Follow-up

Students generate one equivalent fraction for 3/4 using a model and one using
multiplication, then explain which whole each describes.
